# RadixScope 2.0.0

English | [한국어](../ko/releases/2.0.0.md)

The Base-Converter rewrite now provides a complete numeric core, command line and
PySide6 desktop interface under the RadixScope name.

- Exact conversion between bases 2 through 36, recurring fractions and mixed-base expressions
- Multi-base output, explicit rounding and conversion traces
- Fixed-width integer interpretation, bitwise operations, overflow and endian bytes
- Exact IEEE 754 binary32/binary64 encoding and decoding with special-value metadata
- Conversion, Trace, Programmer and IEEE 754 desktop workspaces
- System/light/dark themes, persistent options and lightweight recent history
- Python 3.11+ wheel and source distribution, with GUI dependencies as an optional extra

The old module layout and old configuration files are not migrated. Install the new package
with the GUI extra and launch `python -m radixscope.gui`. See the installation and usage
guides in `docs/` for command examples, signed pattern semantics and display limits.
