# RadixScope 2.0.0

[한국어 README](../../../README.ko.md) | [English](../../releases/2.0.0.md)

Base-Converter를 재작성한 버전으로, RadixScope라는 이름 아래 숫자 처리 코어,
명령줄 인터페이스, PySide6 데스크톱 앱을 제공합니다.

- 2~36진법 사이의 정확한 변환, 순환소수, 혼합 진법 수식
- 여러 진법으로 동시 출력, 반올림 설정, 변환 과정
- 고정 비트 정수 해석, 비트 연산, 오버플로, 엔디언 바이트
- 특수값 정보를 포함하는 정확한 IEEE 754 binary32·binary64 인코딩과 디코딩
- Conversion, Trace, Programmer, IEEE 754 데스크톱 작업 화면
- 시스템·밝은·어두운 테마, 옵션 저장, 간단한 최근 기록
- Python 3.11 이상용 휠과 소스 배포 패키지, 선택적으로 설치하는 GUI 의존성

이전 모듈 구조와 설정 파일은 이전하지 않습니다. GUI 추가 옵션으로 새 패키지를
설치하고 `python -m radixscope.gui`로 실행하세요.
[설치 안내](../install.md), [명령줄 사용법](../cli.md), [데스크톱 사용법](../desktop.md)에서
명령 예제, 부호 있는 비트 패턴 해석, 표시 제한을 확인할 수 있습니다.
